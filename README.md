## Вариант задания

### Тема работы
Разработка семантического анализатора: построение абстрактного синтаксического дерева (AST) для конструкции if-else с блоком действий.

### Примеры верных строк
```java
int a = 5;
int b = 10;
int max;
if (a > b) {
    max = a;
} else {
    max = b;
};
```
# Контекстно-зависимые условия
В рамках лабораторной работы реализованы следующие семантические проверки:

## 1. Уникальность идентификаторов
Переменная не может быть объявлена дважды в одной области видимости.

Пример ошибки:
```java
int x = 5;
int x = 10;  // Ошибка: переменная 'x' уже объявлена
```
## 2. Совместимость типов
Тип инициализирующего значения или присваиваемого значения должен соответствовать типу переменной.

Пример ошибки:

```java
int a = true;  // Ошибка: несоответствие типов
```

## 3. Допустимые значения (для типа int)
Числовое значение должно находиться в диапазоне -2,147,483,648 до 2,147,483,647.

Пример ошибки:

```java
int x = 3000000000;  // Ошибка: число вне диапазона int
```
## 4. Использование объявленных идентификаторов
Переменная должна быть объявлена до её использования.

Пример ошибки:

```java
x = 10;  // Ошибка: переменная 'x' не объявлена
```

# Структура AST

## Типы узлов AST
| Класс узла | Назначение                          | Атрибуты                                            |
|------------|-------------------------------------|-----------------------------------------------------|
| Program    | Корневой узел программы             | children (список дочерних узлов)                    |
| Decl       | Объявление переменной               | var_type, name, value                               |
| If         | Условный оператор if-else           | cond (условие), then (блок then), else_ (блок else) |
| Block      | Блок кода { ... }                   | items (список инструкций)                           |      
| Assign     | Присваивание id = value             | left (переменная), right (значение)                 |
| Var        | Переменная (идентификатор)          | name (имя переменной)                               |
| Num        | Числовой литерал                    | value (значение числа)                              |
| Str        | Строковый литерал                   | value                                               |
| Bool       | Логический литерал                  | value                                               | 
| Compare    | Операция сравнения                  | left, op, right                                     |
| Logic      | Логическая операция (&&, and, or)   | left, op, right                                     |
| Not        | Отрицание (!, not)                  | expr (выражение)                                    |
| Op         | Оператор (сравнения или логический) | value (строковое представление оператора)           |
| Paren      | Выражение в скобках                 | expr (вложенное выражение)                          |
